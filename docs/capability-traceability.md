# 能力追溯表

AgentBank 用固定的本地模拟数据验证业务终态。每项能力都覆盖三条独立旅程：标准输入、口语化多轮输入、边界或恢复输入，共 33 项能力、99 条业务用例。用例不仅检查接口返回，还检查持久状态、账本分录、授权消费、审计事件和幂等结果。

| 场景 | 能力 | 关键终态与评委可核对的证据 |
|---|---|---|
| 基础查询 | Q01 余额、Q02 交易记录 | 只返回当前用户数据；重复请求返回同一持久结果 |
| 智能转账 | T01 姓名转账、T02 手机号转账、T03 备注/别名转账 | 收款人歧义先澄清；确认卡绑定收款账户快照；账本借贷和审计事件一致 |
| 智能转账 | T04 定时转账、T05 AA 收款 | 未来授权限定金额、日期和次数；AA 按分结算；每个操作使用唯一幂等键 |
| 账单分析 | B01 分类明细、B02 异常交易、B03 月报、B04 年报 | 只读本人流水；保留交易 ID、分类依据和缺失数据，仅执行白名单 DSL，不执行任意代码 |
| 理财操作 | W01 产品筛选、W02 产品比较、W03 风险测评、W04 申购、W05 赎回、W06 收益 | 保存测评版本和答案；适当性不匹配拒绝；订单、持仓、赎回和收益分别可查 |
| 卡片管理 | C01 申请、C02 额度、C03 限制、C04 解除限制、C05 挂失、C06 解挂、C07 临时冻结/解冻、C08 PIN | 保护性冻结可快速止损；解挂、提额和 PIN 变更需强验证；PIN 不进入聊天 |
| 订阅管理 | S01 订阅识别、S02 续费提醒、S03 取消订阅 | 候选保留流水证据；提醒去重；取消同时撤销未来扣款授权 |
| 跨场景联动 | X01 生日建议、X02 资金预留、X03 鲜花订单、X04 蛋糕订单、X05 盗刷处置 | 生日计划按 DAG 推进，暂停/取消/失败可恢复；X05 先冻结卡片，再通过设备验证完成挂失，验证失败时卡片仍保持冻结 |

PIN 变更（C08）通过专用安全表单验证，而非把 PIN 放进聊天。其余口语化旅程使用确定性解析和多轮续接，不能据此推导真实模型理解准确率。

## 评测范围

固定评测另外包含 80 条安全用例、27 条误拦用例、10 条额外欺诈用例和 11 条恢复用例，共 227 条用例。所有结果来自本地模拟账户、商户和设备；它们用于复现系统行为，不代表真实银行的线上成功率、误拦率或生产性能。

机器可读的 [用例矩阵](../evals/m2_m3_capability_matrix.yaml) 由 [追溯实现](../backend/agentbank/evals/traceability.py) 映射到处理器和测试函数；运行测试会生成逐条证据 JSON。评委可以先按 [本地评审与演示指南](LOCAL-REVIEW-GUIDE.md) 体验，再查看固定评测 JSON 和 HTTP 自测结果。
