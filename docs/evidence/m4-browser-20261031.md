## 本轮复现并修复

- 姓名收款人下拉框的“使用新收款人”option 没有显式空 value；真实浏览器把中文文案当作 recipient_id，导致 `NOT_OWNER`。修复显式空 value，并加入符合浏览器 option 默认 value 语义的可执行测试。
- 生日计划的服务端显示字段“资金预留（分）”曾直接展示整数分。页面现在按明确单位转换成人民币及中文大写，新增可执行回归。
- WebIM 已知失败优先显示 `explanation.message/next_step`；`CONVERSATION_BUSY` 明确未开始处理，建议稍后作为新消息发送，不提供会重放相同失败 event 的重试按钮。网络错误仍保持相同事件 ID 重试。
