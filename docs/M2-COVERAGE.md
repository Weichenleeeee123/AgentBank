# M2 业务能力逐项覆盖表

这份表只接受业务终态证据：处理器、API、状态持久化、审计和 CAP 用例必须同时存在。`基础` 表示代码已有入口但还需要补不变量或边界；`完成` 只有在对应集群的逐项验收提交后才能填写。

|---|---|---|---|
| Q01 | 查余额 | 完成 | 账面、可用余额、as_of、事实片段、本人隔离 |
| Q02 | 查交易记录 | 完成 | 日期/分类/limit 过滤且只返回本人流水 |
| T01 | 人名转账 | 完成 | 同名消歧、确认后借贷平衡、哈希复核、重放拒绝 |
