## 赛题：银行 AI 智能体（AI 代人操作银行，兼顾安全和体验）
做一个 AI Banking Agent 系统：
- 用自然语言对话理解用户的金融意图，自主规划并执行银行业务操作；
- 用户可以通过 APP、IM 等渠道和 Agent 交互；
- 可参考 OpenClaw 等开源智能体项目，行业对标是 Revolut AIR。

至少覆盖下面 3 个核心场景，鼓励全部覆盖：

| # | 场景 | 典型能力 |
|---|---|---|
| 1 | 智能转账 | 按人名、手机号或备注转账；定时转账；拆分 AA 收款 |
| 2 | 账单分析 | 消费分类统计；异常交易识别；月度和年度账单报告 |
| 3 | 理财操作 | 产品推荐与对比；风险评估；一键申购和赎回 |
| 4 | 卡片管理 | 申请卡；调整额度；设置和解除交易限制；挂失 |
| 5 | 订阅和代扣管理 | 自动识别订阅扣费；续费提醒；一键取消订阅 |
| 6 | 跨场景联动 | 例如检测到"我爱人生日"，当月锁定 1000 元活期，生日前 2 天订鲜花和蛋糕 |

## 核心技术要求
1. 权限分级（优先级：高）

| 级别 | 执行策略 | 典型操作 |
|---|---|---|
| 绿色 | 自动执行 | 查余额、查交易记录、账单分析、查理财收益等纯查询，确认意图后直接执行 |
| 黄色 | 用户确认 | 小额转账（日累计 ≤ 1000 元）、查询或取消订阅、申请虚拟卡等，执行前展示操作详情并获得明确确认 |
| 红色 | 强验证 | 大额转账（日累计 > 1000 元）、改密码、挂失和解挂、申购理财等，需要人脸识别、短信验证码或 U 盾等多因子认证 |

2. 安全机制（优先级：高）
   - 防幻觉：不得编造交易结果或账户信息。
   - 防注入：不能用特殊 Prompt 绕过权限控制。
   - 审计：所有关键操作都要记录完整的决策链路和执行日志。
   - 熔断：连续失败或出现可疑行为时触发安全锁定。
   - 沙箱：生成的代码要在受限、可监控、逻辑隔离的环境里运行。
3. 意图理解和任务规划
   - 能识别模糊表达、省略的上下文和隐含意图。
   - 复杂任务拆成有序的子任务 DAG。
   - 执行过程中可以中断、回退，也可以转人工接管。

## 评分（人工智能赛道）
- 任务完成率 40%：典型金融场景任务的完成情况、多步骤规划是否合理、工具调用是否正确。
- 安全合规 30%：能否防住诱导转账、信息套取、越权操作和 Prompt 注入，敏感操作有没有确认和风险提示。
- 创新和交互体验 30%：场景新不新、是否解决真实问题、对话轮次效率、追问、错误恢复、口语化输入、超范围问题的兜底。
