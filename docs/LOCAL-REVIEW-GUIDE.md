# 评委体验指南

行止（ActSure，内部项目名 AgentBank）提供本地可运行的银行 AI 智能体。账户、交易、商户和设备均为模拟数据，不涉及真实资金。

## 从哪里开始

源码仓库（内部项目名 AgentBank）：[AgentBank](https://github.com/Weichenleeeee123/AgentBank)。在项目根目录按 [安装与启动说明](LOCAL-RELEASE.md) 安装依赖并启动评测服务，然后打开 [银行 App](http://127.0.0.1:8001/app/)。`127.0.0.1` 指正在运行服务的本机，不能作为远程演示链接使用。

| 体验内容 | 前置条件 |
|---|---|
| 余额查询、基础转账、安全表单与固定评测 | 本地服务运行即可，无需模型 API Key |
| 自由口语理解与模型规划 | 按 `.env.example` 配置主模型服务并重启本地服务 |
| 红色业务的设备验证 | 为演示用户签发一次性配对码，在模拟手机页完成配对 |
| 自动评测与人工坐席 | 使用本机生成的管理员或坐席令牌 |

## 第一条体验路径：查询与小额转账

1. 在 App 选择演示账户 `user_001` 并进入会话。
2. 输入“查余额”，记录当前余额。
3. 输入“给房东转账”。系统要求补充金额时，输入“20 元”。
4. 核对确认卡上的收款人、账户及金额，再点击确认。此时才允许实际记账。
5. 再次查询余额和交易记录，核对减少 20 元及对应流水。新建种子账户初始余额为 5000 元；已有演示数据以本次查询结果为准。

这条路径展示绿色查询、信息补充、黄色确认及最终结果。确认卡绑定对象和金额；若已有付款累计、账户限制或风险状态触发升级，应按页面要求处理，不把“待确认”“待验证”当作已完成。

## 设备验证

保持服务运行，在项目根目录另开 PowerShell：

```powershell
./scripts/New-DevicePairing.ps1 -UserId user_001
```

在 [模拟手机](http://127.0.0.1:8001/app/device.html) 输入返回的一次性配对码。设备凭证与银行会话独立。

回到 App，在专用安全表单中选择本人卡片并准备模拟 PIN 变更。确认后到模拟手机页读取本次验证码，再回到 App 表单输入并提交。PIN 和 OTP 均不放入聊天。可查看操作状态和回执，核对成功信息来自服务端结果。

## 进一步体验

| 场景 | 操作方式 | 重点观察 |
|---|---|---|
| 模拟 IM | 打开 [Web IM](http://127.0.0.1:8001/app/webim.html)，连接独立 IM 身份并显式绑定银行账户，再办理小额转账 | 多轮对话与确认可接续；红色业务跳转 App 验证；群聊仅展示通用状态 |
| 生日计划 | 配置模型后通过生日需求准备计划，在返回的计划链接中核对预算、报价和时间并授权 | 六节点 DAG、资金预留、等待执行、暂停、恢复和取消；已执行部分与未执行部分分别展示 |
| 盗刷处置 | 请求处理疑似盗刷并检查卡片状态 | 先确认冻结，再验证挂失；后续验证失败时卡片仍保持冻结 |
| 人工协助 | 打开 [坐席台](http://127.0.0.1:8001/app/staff.html)，使用本机坐席令牌处理待办 | 坐席仅提交建议与重试申请，执行付款仍需用户授权 |
| 固定评测 | 打开 [评测面板](http://127.0.0.1:8001/app/eval.html)，使用本机管理员令牌运行自测 | 逐条结果、业务终态、审计校验和未授权记账检查 |

评测模式允许快进业务时钟以观察未来任务到期，不能缩短真实时间冷静期。计划页应从 App 返回的计划链接进入，以携带正确计划标识和会话上下文。

## 本地令牌在哪里

启动器在 `.tmp/local-demo/eval.env` 中保存评测模式的独立凭证：`AGENTBANK_ADMIN_TOKEN` 用于评测面板，`AGENTBANK_STAFF_TOKEN` 用于坐席台。操作者在本机查看并填入对应页面的令牌框，不将令牌放入聊天、URL、截图或提交材料。设备配对码由脚本另行生成，不使用管理员令牌代替。

## 如何判断是否完成

| 状态 | 含义与下一步 |
|---|---|
| `awaiting_confirmation` | 等待用户核对确认卡，尚未完成 |
| `awaiting_mfa` | 等待设备验证，尚未完成 |
| `scheduled` / `waiting_trigger` | 已安排未来任务，尚未执行完毕 |
| `cooling_off` | 等待真实时间冷静期，随后重新确认和验证 |
| `unknown` | 结果不明，先查账或联系人工，不另发一笔付款 |
| `partially_completed` | 仅部分节点完成，需要查看未完成项和补偿结果 |

成功以业务终态、账本或订单记录为准。重复点击与网络重试应沿用原请求标识，避免发起新的业务意图。

## 常见启动问题

- 页面打不开：确认启动终端仍在运行，默认地址使用端口 8001；公共模式端口为 8000，且不开放管理自测和坐席接口。
- 自由口语未被识别：无模型配置时仅支持受限规则输入；可以先体验上述固定话术和安全表单，再配置模型。
- 收不到验证码：确认配对用户与 App 用户一致，且已产生待设备验证的操作；验证码到期后重新准备并核对操作。
- 评测面板提示未授权：使用评测模式生成的管理员令牌，而非 App 会话或坐席令牌。

安装、模型配置、Docker 配置和测试命令见 [本地运行说明](LOCAL-RELEASE.md)。
