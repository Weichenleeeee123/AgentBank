# 安全自评（M3 本地模拟）

本地证据与复现命令见 [M3-LOCAL-EVIDENCE.md](M3-LOCAL-EVIDENCE.md)，逐项对应见 [M3-COVERAGE.md](M3-COVERAGE.md)。

## 已验证行为

- 确认和 MFA 提交均复核 owner、receipt、action/display hash、revision、有效期与用户锁定；伪造授权及跨用户调用不产生账本副作用。
- high 在提交前拒绝并转人工；服务端风险记录不由模型参数覆盖。medium/unknown 冷静期使用真实时间，并占用可用余额；期满后二次确认签发新的短效 MFA 凭证，验证后才提交，取消释放占用。
- OTP 三次失败按用户持久化锁定，重新登录不清零；成功后重置连续失败计数；过期锁定记录可重新开始窗口。
- 认证 API 伪造/越权自动写入安全计数。冻结、增加限制和降额保留，解冻、提额不属于保护性例外。
- U18 基础设施失败熔断和模型调用预算有实际运行时检查；查询不被工具写熔断阻断。
- unknown 恢复沿用原 ID，不重新派发资金命令；Saga 补偿故障逐项报告，未补偿项仍需人工核实。
- 审计链全字段校验，数据库外 HMAC 检查点可检测数据库连同库内 checkpoint 一起截断；审计 payload 做 DLP。
- 80 条 SEC 用例每条核查它实际使用的数据库中的 operation、receipt consumption 和借贷分录；自测报告的未授权分录由这些检查汇总，缺证据时不显示测量通过。
- M4 收口新增回归：同会话并发、失败消息持久重放、IM 绑定与跨 session nonce、群聊红色回调隐私、收款账户快照绑定、整数分精度、PIN 展示哈希及 OTP 后二次校验。逐项修复提交和最终统一门禁以 [M4-LOCAL-CANDIDATE.md](M4-LOCAL-CANDIDATE.md) 为准。

## 指标含义与边界

- 227 例是固定本地回归集：99 CAP、80 八类 SEC、27 FP、10 额外 fraud、11 M3。FP 匹配失败反映这些样例中的分类误判，不能直接推断真实业务四类误拦率。
- 模拟 OTP 不是真实短信、人脸或 U 盾；设备 token 只证明模拟页面和 App 会话的访问边界。
- 本地会话接口允许选择种子演示用户，不能作为真实登录认证上线。PIN 业务验证授权与状态流转，不保留新 PIN，也不接入真实卡密码系统。真实用户认证、KMS 和机构接口属于生产化边界。
- 无模型 provider 时，保留确定性规则/表单路径；已配置 provider 失败的分类不会被当成安全许可。线上备用 provider 与真实租户未由这些测试替代。
- U18 工具熔断为进程内状态，服务重启会重置；用户的 OTP/安全拦截计数与模型预算存 SQLite。
- HMAC 密钥若未配置，则在本地数据库旁生成独立 key 文件；实际部署应配置独立秘密并限制访问、备份检查点。拥有密钥的人可伪造检查点；最后检查点之后尚未完成的尾段仍有截断窗口。
- Docker、CI、公网 HTTPS、飞书真实协议/租户和真实商户/银行分别验收，本轮不宣称 M4 发布完成。
