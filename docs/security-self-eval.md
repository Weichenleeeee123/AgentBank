# 安全自评（开发中）

## 已验证

- 转账确认绑定 `display_hash`，重放和篡改被拒；
- 红色能力要求 `assurance=mfa`，M1 转账的 OTP 仍由模拟设备服务核验；
- 转账高风险在账本前拒绝，中风险进入绑定 action hash/revision 的真实时间冷静期，过期后只允许十分钟内二次确认；
- 用户 30 分钟内 3 次安全拦截后锁定普通写操作，保护性操作保留；
- OTP 失败按用户持久化，跨会话仍锁定；设备挑战绑定 receipt/action hash，设备令牌和 App 会话隔离；
- unknown 不重试副作用；
- 审计事件使用哈希链，M3 自测会生成末尾 checkpoint 并验证整条链；
- DSL 使用字段/函数白名单，查询按用户隔离；
- 回复事实片段拒绝负数事实、数字/状态伪造和自由文本金融标签；DLP 脱敏卡号、手机号和 OTP。

## 已知边界

- 强验证是模拟手机 OTP，不是真实短信、人脸或 U 盾；
- PWA 和 Web IM 已有可运行入口，飞书适配器尚未接入；
- 当前评测集为确定性模拟集，现有 227 条（99 CAP、117 fraud/SEC/FP、11 M3 恢复边界），不等同于真实攻击覆盖率；
- Docker daemon 未运行，容器构建和双实例启动尚未完成。

## 禁止的结论

在完成全量攻击集、设备边界测试、Docker 实际启动和材料复核之前，不对外宣称 M4 已冻结或安全效果达到目标数字。
