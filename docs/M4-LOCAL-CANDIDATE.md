## 最终本地门禁

按 [README](../README.md) 或 [LOCAL-RELEASE](LOCAL-RELEASE.md) 在新环境中安装锁定依赖后，执行 `python scripts/release.py`；需要源码包时执行 `python scripts/release.py --package`，其中 `python` 应指向该独立环境。

门禁覆盖依赖一致性、Ruff、严格 Mypy、全部 Python 测试、全部前端测试和 JS/MJS 语法、当前 227 条确定性评测，以及 HTTP 管理员自测。自测要求全部检查通过、审计验证通过、账本写入有实测且未授权写入为零；HTTP 自测使用 TestClient，不代表网络部署测试。

每轮在唯一 `.tmp/releases/<时间>-<唯一标识>` 下保留 `gates.json`、逐门禁原始输出、逐评测用例 JSON 和 HTTP 自测响应。所有必选门禁通过、源码在验证期间未变，才生成 `manifest.json`；加 `--package` 才生成源码 ZIP。清单记录提交、每个源码文件摘要、总摘要与外部门禁状态。源码范围包含后端、提示词、前端资源、契约/策略、评测、测试、文档、CI 工作流和锁文件；源码包需要网络下载锁定依赖，不是离线 wheel 包。

当前最终清单与源码候选包尚待收口后生成。完成时应引用实际证据目录和摘要，而不是在多个文档里手工维护可能过期的测试数。
